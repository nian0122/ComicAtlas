# 导入自动分类与自动标签

## 目标

导入 Worker 负责解析来源并输出元数据；API 在 `ImportPersistenceServiceImpl` 的事务落库边界补全缺失的分类和标签。这样规则不依赖 Worker 的来源格式，也不会把业务写操作放到 Worker。

## 规则

1. ComicInfo 或来源元数据提供分类时保留原值；若该名称与现有 `category` 词条完全匹配，同时写入 `comic.category_id`。
2. 分类缺失时，把标题、日文标题、作者、简介和显式标签合并为检索文本，从数据库现有分类中选择包含匹配项的最长名称。没有可靠匹配时保持为空，不自动创建分类。
3. 显式标签写入 `tag.type=COMICINFO`。检索文本命中受控关键词表时补充标签，写入 `tag.type=AUTO`；已由 ComicInfo 提供的同名标签不重复补充。
4. 漫画与标签关联通过 `comic_tag` 幂等写入。自动标签规则是确定性的，不调用外部模型，导入重试不会产生新的关联。

## 边界与演进

当前关键词表覆盖颜色、篇幅、合集、动画/视频和分辨率等可从文件名或简介稳定判断的信号。需要人工维护的分类必须先在分类管理中创建；后续若增加可配置规则，应保留显式元数据优先级，并为规则版本增加回归测试。

## 验证

`AutomaticMetadataClassifierTest` 覆盖最长分类匹配、显式值优先和无匹配；`ImportPersistenceServiceTest` 覆盖导入落库时 `category_id` 与 `AUTO` 标签的实际写入。
