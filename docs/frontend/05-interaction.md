# 05 — 交互设计

**更新日期：** 2026-08-12
**状态：** 与 v1.5 现状同步
**维护者：** ComicAtlas 前端组

> 页面怎么操作。只讨论行为，不讨论颜色、字体、圆角。聚焦点击、键盘、滚动、Hover、状态切换。

---

## Library（漫画库）

### 搜索

| 操作 | 行为 |
|------|------|
| 输入文字 | 300ms 后自动搜索，不显示 loading，结果直接替换列表 |
| 清空 | 恢复全部漫画列表 |
| Enter | 立即搜索（不等 debounce） |

### 标签筛选

| 操作 | 行为 |
|------|------|
| 点击下拉 | 显示所有标签 |
| 选择标签 | 立即筛选 |
| 清除 | 恢复全部 |

### 排序

| 操作 | 行为 |
|------|------|
| 点击下拉 | 显示排序选项 |
| 切换 | 立即重新排序 |

### 漫画卡片

| 操作 | 行为 |
|------|------|
| 点击 | 跳转 Comic Detail |
| Hover | 卡片阴影加深 |

### 分页

| 操作 | 行为 |
|------|------|
| 点击页码 | 加载对应页 |
| 搜索/筛选 | 重置到第 1 页 |

### 空状态

当没有任何漫画时，显示引导提示："还没有漫画，去导入一本吧" + 按钮跳转 `/manage/import`。

---

## Comic Detail（漫画详情）

### 操作按钮

| 按钮 | 行为 |
|------|------|
| 继续阅读 | 跳转 Reader（上次位置） |
| 从头开始 | 跳转 Reader（第 1 章第 1 页） |
| 生成LQ | 发送请求 → Toast 提示"已提交" → 任务中心 / 存储管理可查看进度 |
| 删除漫画 | 弹出确认 → 确认后进入回收站流程（软删除，7 天保留期；永久清理需二次确认） |

### Catalog 树

| 操作 | 行为 |
|------|------|
| 展开/折叠 | 点击目录名（如 "Vol.1"）切换展开状态 |
| 点击章节 | 跳转 Reader（该章节第 1 页） |
| 默认状态 | 全部展开 |

---

## Reader（阅读器）— 核心页面

### 图片区域

| 操作 | 行为 |
|------|------|
| 点击左侧 1/3 | 上一页 |
| 点击右侧 2/3 | 下一页 |
| 鼠标滚轮 | 滚动查看当前页（长图） |
| 图片加载中 | 显示骨架屏（aspect-ratio 保持比例） |
| 图片加载失败 | 显示"加载失败"占位 |

### 工具栏

| 元素 | 行为 |
|------|------|
| 返回按钮 | 返回 Comic Detail |
| 章节标题 | 显示当前章节名 |
| 页码 | 当前页 / 总页数 |
| 上一章按钮 | 跳转上一章第 1 页 |
| 下一章按钮 | 跳转下一章第 1 页 |
| 设置按钮 | 打开设置抽屉 |

### 键盘快捷键

| 按键 | 行为 |
|------|------|
| ← / A | 上一页 |
| → / D | 下一页 |
| Space | 下一页 |
| ESC | 返回 Comic Detail |

### 设置抽屉

| 选项 | 行为 |
|------|------|
| 画质模式 | `AUTO`（省流优先）/ `HQ_ONLY`（原图）/ `LQ_ONLY` |
| 适配模式 | `AUTO` / `WIDTH` / `HEIGHT` / `ORIGINAL` |
| 缩放 | 50%–200%（`ZOOM_LEVELS`） |
| 阅读方向 | `ltr` / `rtl` / `vertical` / `horizontal` |
| 预加载 | 预加载窗口（`preloadWindow`）+ 开关（`enablePreload`） |

设置由 `stores/reader-settings-store.ts` 持久化到 `localStorage`。

### 进度记录

| 行为 | 触发条件 |
|------|----------|
| 自动同步 | 每翻 5 页自动保存 |
| 离开时同步 | 页面卸载时保存当前页 |

### 章节结束

读到最后一页时，"下一章"按钮高亮提示，或自动弹出"下一章"选项。

## Import（导入，管理端 `/manage/import`）

| 操作 | 行为 |
|------|------|
| 选择来源 | 下拉切换 ZIP 文件 / DIRECTORY 本地目录（EHENTAI 由 API 支持，前端暂未提供选项） |
| 输入路径 | 文本框输入（ZIP 文件路径 或 本地目录路径） |
| 批量导入 | 多条本地目录路径，一次创建多个任务（批量仅 DIRECTORY） |
| Enter | 提交 |
| 提交按钮 | 发送请求 → Toast "导入任务已创建" → 清空输入 → 跳转任务中心查看进度 |

---

## Task Center（任务中心，管理端 `/manage/import/tasks`）

| 操作 | 行为 |
|------|------|
| 页面加载 | 立即拉取最新任务列表 |
| 自动轮询 | 有进行中任务时轮询刷新，无任务时停止 |
| 取消 | 进行中任务 → 点击取消 → Toast "已取消" |
| 重试 | 失败任务 → 点击重试 → Toast "已重试" |
| 立即阅读 | 完成任务 → 跳转 Comic Detail 或 Reader |

### 状态颜色

| 状态 | 左侧边框颜色 |
|------|-------------|
| 进行中 | 蓝色（accent） |
| 失败 | 红色 |
| 完成 | 绿色 |

|------|------|
| 点击记录 | 跳转 Reader（恢复上次 chapter + page） |

## 全局导航（已实现）

`components/layout/TopNav.vue` + 各 Layout（`ReadingLayout` / `ReaderLayout` / `ManagementLayout`）：

| 区域 | 跳转 |
|------|------|
| 阅读端导航 | Home `/`、Library `/library`、History `/history` |
| 管理端导航 | 漫画工作区 `/manage/comics`、任务中心 `/manage/import/tasks`、存储管理 `/manage/storage` 等 |

**行为**：
- 当前页面高亮
- 点击跳转无整页刷新（SPA 路由）
- 移动阅读设备访问 `/manage/*` 由路由守卫重定向到 `/manage/intercept` 拦截页

## 通用交互原则

1. **即时反馈**：列表搜索、标签筛选不显示 loading，结果直接替换
2. **Toast 提示**：操作成功/失败使用轻量 Toast，不弹 Dialog
3. **空状态引导**：列表为空时显示引导文字 + 操作按钮，不显示空白页
4. **危险操作确认**：删除需要 Popconfirm 二次确认
5. **自动轮询**：任务中心 3 秒刷新，无需手动刷新按钮
