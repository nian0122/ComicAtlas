## 公共层与重复代码处理

- 控件默认高度、圆角、字号和边框收口至 `app/styles/element-plus.scss`，按需加载的组件 CSS 不再覆盖公共尺寸。管理漫画、存储和 PC 漫画库共用 `filter-controls.scss`；管理筛选的字段标题、间距与 Select 宽度也在此定义。
- 删除元数据页、漫画编辑页、工作台搜索及批量工具栏中的重复控件主题。修复未定义的颜色、表面、字号令牌，并建立 `check:styles` 门禁；运行时 `--app-viewport-height` 由 App 写入，第三方 `--el-*` 变量独立处理。
- 章节列表复用 `ChapterRow` 的目录外观变体，保留 `CatalogChapterRow` 的兼容入口。两个 AI 页面共用任务状态、轮询、结果和标题展示。
- 导入预览与扫描页面共用 `ScanWarningChip`；漫画、章节和媒体标记共用 `ReactionBadge`，强调外观通过属性表达。
- 内容标记面板包含修改与回收动作，迁入 `features/content-reactions`。实体层保留 API、类型与展示组件；页面通过功能层 public API 引用。
- 删除桌面详情页已无调用的搜索按钮样式；详情容量使用公共字节格式化方法。

以下相似规则保留在所属切片：不同表格的列布局、导入表单与扫描树的间距、工作台与上传页的文件列表尺寸、阅读进度条、媒体占位画布和特定导航布局。这些声明服务于不同的结构和响应式行为，不构成第二套公共控件主题。移动阅读筛选的胶囊样式与阅读器浮层尺寸按产品交互保留。
