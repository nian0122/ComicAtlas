# ComicAtlas 3.0.0-rc.6

本次只修正发布文档、安装说明和仓库展示信息，Go、Web 与 AI 运行源码与 3.0.0-rc.5 相同，数据库结构和数据保持兼容。

- 重写 README：补充功能清单、系统要求、数据与端口、备份/恢复/升级/回滚、卸载、2.x 迁移限制、AI 配置和安全说明。
- 明确首次构建会编译 FFmpeg、x264、libjpeg-turbo 和 libwebp，需要网络、较长时间和数 GB 磁盘。
- 明确管理端没有登录认证，两个入口默认只绑定本机。
- 明确版权与使用范围，补充问题反馈入口。
- Compose 镜像标签更新为 3.0.0-rc.6。

## 升级

与 3.0.0-rc.5 相同：保留 `.env`、SQLite 卷 `comicatlas_database` 和存储目录，替换源码后执行 `start.cmd` 或 `sh start.sh`。本次没有数据库迁移变化；回退时使用升级前的数据库备份。
