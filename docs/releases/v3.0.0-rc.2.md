# ComicAtlas 3.0.0-rc.2

修复 rc.1 源码包遗漏的 Go 存储模块和 Web 存储实体。Compose 首次启动从源码构建应用镜像，Docker 镜像加速仍用于基础镜像。

- Go 和 SQLite 提供独立的阅读与管理接口，Vue 提供两个本地 Web 入口。
- 支持漫画导入、图片和视频阅读、阅读进度、收藏与评价，以及媒体存储、轻量副本、任务和回收站管理。
- 使用仓库根目录的 Docker Compose 从源码构建和部署。SQLite 数据和托管媒体分别保存在数据库卷和宿主机存储目录。

旧版 MySQL 数据需要单独迁移。请在升级前备份旧库和媒体，并按 [安装说明](../../README.md)准备新版环境。

## 验证状态

- 已验证 Docker Compose 构建、阅读与管理入口隔离、CBZ 导入、图片读取及重建容器后的数据持久化。
- 管理端仍有五项浏览器用例在复测中失败，涉及批量选择与键盘焦点、上传重试和逐本整理。
