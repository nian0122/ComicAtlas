# ComicAtlas v1.0.0 发布说明

**版本**：1.0.0  
**发布分支**：`main`  
**定位**：面向个人用户的本地漫画仓库稳定版本

## 本版本包含

- ZIP、本地目录和 EHENTAI 来源导入
- 异步导入任务、失败重试和取消
- 漫画库、目录树、详情编辑、标签与分类管理
- 图片与视频混排阅读
- 阅读历史和断点续读
- LQ 生成、HQ 删除、存储统计和文件状态管理
- Docker Compose 部署方式与统一 MANAGED 存储布局

## 使用入口

- 用户端：`http://localhost`
- 管理后台：`http://localhost/manage`
- 安装与操作步骤： [用户指南](../user-guide.md)

## 分支策略

- `main`：1.0 用户稳定版本，只合入经过验证的发布内容。
- `develop`：后续开发分支，用于新功能、修复和下一版本准备。

## 已知限制

- LQ 需要手动触发，不会自动生成。
- 管理后台面向桌面浏览器，移动设备默认拦截管理路由。
- Redis、RabbitMQ、Nacos 在当前 Compose 中按外部基础设施配置，需要部署或通过 SSH 隧道提供。
- Reader 暂不提供双页、缩放、全屏和阅读方向切换等高级模式。

## 发布前检查

发布前应执行 [稳定版发布检查清单](../testing/release-checklist.md)，至少完成前端构建、后端打包、服务启动和一条真实漫画导入—阅读—历史恢复链路验证。
