# ComicAtlas v2.0.1 发布说明

**版本**：2.0.1  
**发布日期**：2026-08-21  
**基线**：`v2.0.0..v2.0.1`

## 本次更新

- 调整局域网媒体缓存策略。
- 视频首帧改为按需加载，并复用首帧会话缓存。
- 完善漫画库分页状态、筛选栏动画、筛选排序和结构页自适应。
- 管理端新增漫画实时搜索。
- 正式发布树不包含开发测试代码；`docs/promo/` 继续作为本地宣发资料目录忽略。

## 已知限制

- `e-hentai.org` 漫画下载对接尚未完成。
- 自动分类标签功能尚未实现。

以上事项保留为后续版本开发内容，不影响本次 2.0.1 稳定版发布。

## 验证

- 前端构建：`frontend/pnpm build`。
- 后端打包：`mvnw -DskipTests package`。
