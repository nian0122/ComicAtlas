# ComicAtlas 3.0.0-rc.4

- 目录导入统一使用 staging/import 任务工作区，按目录组搬移媒体，并按原结构还原非媒体资料。
- 移出到文件夹统一为一次确认和单任务状态，细化存储失败诊断。
- 优化轻量图片并发生成、超大 JPEG 解码和暂存空间使用，统一封面读取与轻量副本路径。
- 新增应用内 SQLite 快照定时器，支持配置独立导出根目录。
- 调整批量资料编辑、目录批量删除、管理列表虚拟滚动和分页，修复视频多段悬停试看和短视频全屏体验。
- 应用层文件校验改为文件属性，移除 SHA-256 摘要字段和对应流程。
- 发布 Compose 的后端临时空间上限调整为 2 GiB，与当前图片处理构建配置对应。

## 升级

保留原实例的 Compose 项目名、.env、SQLite 卷和媒体目录。升级前停止写入并备份 SQLite 与完整媒体，随后用新版源码执行 docker compose up -d --build --wait。启动会应用新的数据库迁移，回退时需要配套恢复升级前的数据库备份。
