# ComicAtlas 2.2.0

发布日期：2026-10-08。

## 用户功能

- 更新漫画库、管理后台、目录和章节操作界面。
- 提供喜欢页面与分层收藏浏览、阅读位置恢复、全屏与短视频阅读。
- 存储统计改为后台容量快照，优化封面体积与懒加载。
- 完善任务终态保护、目录导出与失败恢复。
- 修复 ZIP 解压失败时残留无效临时目录，保留整理阶段的恢复现场。

## 安装与升级

从[项目首页](../../README.md)安装。用户只需 Docker，应用在镜像中构建，无需本机开发工具。main 统一使用 docker-compose.yml 启动全部本机服务，容器通过内部服务名连接 MySQL、Redis、RabbitMQ 和 Nacos。

Worker 增加 aria2 运行依赖。首次安装需建立仅有 SELECT 权限的 Worker 账号。

生产日志默认使用 INFO。本机基础设施关闭 Nacos 认证，客户端无需配置凭据。

从 2.1 升级前备份数据库和漫画存储，保留 .env，暂停任务后重新构建启动。Flyway 自动迁移，不能只替换前端文件。回退须同步恢复升级前的数据库备份。

## 发行边界

main 仅选入运行源码、生产构建配置、部署和文档；研发分支继续保留完整测试与开发工具。发行树移除 Java 测试、前端测试、Go 测试、E2E、测试夹具、演示页面、IDE 配置、Maven Wrapper、开发/QA 脚本和测试框架依赖。发布门禁同时检查这些路径。

## 使用限制

管理端默认无业务鉴权，面向可信个人环境。main 不提供公网入口；开发者的穿透工具和公网测试配置保留在 develop。AI 本地模型需要另备兼容硬件及模型文件。导出产物位于本机 export 目录，不提供浏览器下载接口。
