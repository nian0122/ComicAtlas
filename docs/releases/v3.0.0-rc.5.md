# ComicAtlas 3.0.0-rc.5

- 新增 `start.cmd`、`start.ps1`、`start.sh` 一键启动：首次运行自动生成 `.env`、创建存储目录、处理 Linux 属主，再执行 Compose 构建并启动。
- 安装文档改为一条命令，补充自定义存储目录和不重新构建启动。
- 发布 CI 增加启动脚本准备模式与语法校验。
- 本次不修改 Go 和 Web 运行源码，数据库结构和数据与 3.0.0-rc.4 兼容。

## 升级

保留原实例的 Compose 项目名、`.env`、SQLite 卷和存储目录，替换源码后执行 `start.cmd` 或 `sh start.sh`（也可以继续使用 `docker compose up -d --build --wait`）。本次没有数据库迁移变化；回退时仍需使用升级前的数据库备份。
