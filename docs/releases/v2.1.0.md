# ComicAtlas v2.1.0 发布说明

**版本**：2.1.0
**发布日期**：2026-08-22
**基线**：`v2.0.1..v2.1.0`

## 本次更新

- 新增 CBZ 漫画导入支持。
- 新增 `ComicInfo.xml` 元数据解析、落库和详情展示。
- 导出支持 ZIP/CBZ 格式，并在 CBZ 中生成 `ComicInfo.xml`。
- 完善标准分卷压缩包的导入、导出和格式识别。
- 整理 Worker、管理端和阅读端业务目录，统一模块边界和运行配置。
- 完善导入重试、元数据刷新、任务处理和存储路径校验。

## 数据库迁移

本版本新增 Flyway 迁移 `V24__add_export_format.sql`，用于保存导出格式。升级前请完成数据库备份，启动 API 服务后由 Flyway 自动执行迁移。

## 使用提示

- CBZ 导入时可在压缩包中放置 `ComicInfo.xml`；缺少该文件时仍可正常导入。
- CBZ 导出会生成 `ComicInfo.xml`，压缩包和分卷产物仍保存在宿主机 `MANGA_ROOT/export/`，不提供 HTTP 文件下载。
- 正式发布树不包含测试代码、开发启动脚本和 E2E 夹具；`docs/promo/` 继续作为本地宣发资料目录忽略。

## 已知限制

- `e-hentai.org` 漫画下载对接尚未完成。
- 自动分类标签功能尚未实现。

以上事项保留为后续版本开发内容。
