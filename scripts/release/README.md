# scripts/release

发布脚本目录。

- `verify-release-tree.ps1`：检查 Git 跟踪路径，拦截开发脚本、Java 测试、前端测试、Go 测试、E2E、测试夹具、测试框架配置、演示页面与 IDE 配置。
- 默认校验当前索引；使用 `-Ref main` 或 `-Ref v2.2.0` 校验指定提交树。候选分支合入 `main` 前、合入后打标签前均须通过。
- 构建所需的 FSD、样式、类型检查器继续保留；运行部署说明见[首页](../../README.md)。
- main 仅提供 Docker 本地部署；门禁同时拦截开发者使用的远端连接、穿透、公网入口、个人站点及前端公网开关。
