# 样式目录规范

全局样式由 `index.scss` 统一加载，应用入口只导入这个文件。加载顺序为第三方样式、设计令牌、基础样式、组件库主题和公共动画。

| 位置                | 职责                                         |
| ------------------- | -------------------------------------------- |
| `tokens.css`        | 颜色、间距、字号、圆角等设计令牌的唯一来源   |
| `base.css`          | 原生元素、页面基础、可访问性和滚动条         |
| `element-plus.scss` | Element Plus 变量映射与全站统一外观          |
| `animation.css`     | 公共动画与过渡                               |
| `pages/reading/`    | 阅读端抽离的页面样式                         |
| `pages/management/` | 管理端抽离的页面样式，复杂页面按区域拆子目录 |

页面样式通过 `<style scoped src="@/pages/...css">` 引用，禁止加入全局入口，保留隔离和按需加载。新增独立页面 CSS 统一放入 `pages/`，不再在 `views/` 中创建样式目录或同名 CSS。组件私有样式继续就近保留在 Vue 文件中，无需机械拆出小样式块。

页面只定义布局和特有表现；通用按钮、输入框等外观在主题或公共组件维护。颜色与尺寸标准优先消费设计令牌。修改子组件外观优先提供属性、插槽或 CSS 变量；使用 `:deep` 和 `!important` 时说明必要约束，避免重复覆盖主题。
