# 样式目录规范

全局样式由 `index.scss` 统一加载，应用入口只导入这个文件。加载顺序为第三方样式、设计令牌、基础样式、组件库主题和公共动画。

| 位置                          | 职责                                       |
| ----------------------------- | ------------------------------------------ |
| `tokens.css`                  | 颜色、间距、字号、圆角等设计令牌的唯一来源 |
| `base.css`                    | 原生元素、页面基础、可访问性和滚动条       |
| `element-plus.scss`           | Element Plus 变量映射与全站统一外观        |
| `filter-controls.scss`        | 桌面筛选控件与筛选字段的公共契约           |
| `animation.css`               | 公共动画与过渡                             |
| `src/pages/<分组>/<页面>/ui/` | 页面私有样式，不属于全局样式目录           |

页面样式通过 `<style scoped src="@/pages/...css">` 引用，禁止加入全局入口，保留隔离和按需加载。新增页面 CSS 放在该页面切片的 `ui/`，禁止散落在 pages 分组下或由其他页面引用。组件私有样式继续就近保留在 Vue 文件中，无需机械拆出小样式块。

页面只定义布局和特有表现；通用按钮、输入框等外观在主题或公共组件维护。颜色与尺寸标准优先消费设计令牌。修改子组件外观优先提供属性、插槽或 CSS 变量；使用 `:deep` 和 `!important` 时说明必要约束，避免重复覆盖主题。

桌面表单的默认高度、圆角、字号和边框统一在 `element-plus.scss` 中维护；漫画库、管理漫画与存储筛选通过 `filter-controls.scss` 共用筛选控件规则。移动阅读筛选保留独立的胶囊布局，阅读器浮层也保留适合阅读操作的尺寸。

`pnpm check:styles` 检查源码中未定义的样式令牌和页面重复定义的表单主题，已纳入 `pnpm check`。章节行使用同一组件的目录外观变体；两个 AI 分析入口共用任务状态、结果与轮询生命周期。页面仍负责各自布局，管理和阅读的筛选业务参数分别维护。
