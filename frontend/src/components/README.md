# 公共组件归属

> **TODO FSD-05 / FSD-20**：本目录是迁移前的公共组件过渡层。纯展示组件将迁入 `shared/ui`，应用级组合组件将迁入 `widgets`；完整范围、依赖方向和验收要求见[前端 FSD 改造 TODO](../../../docs/frontend/fsd-refactoring-todo.md)。在对应迁移完成前，不得在此目录新增业务组件。

此目录集中管理跨业务复用的组件。业务专属组件继续放在 `features/<业务>/components/`，页面私有组件放在所属页面附近的 `components/` 子目录。

| 目录          | 职责                                         |
| ------------- | -------------------------------------------- |
| `brand/`      | 应用品牌标识                                 |
| `icons/`      | 通用图标适配                                 |
| `status/`     | 无业务枚举映射的状态外观                     |
| `management/` | 管理页头、面板、统计栅格和空态等公共展示组件 |
| `layout/`     | 应用级导航等组合组件，允许编排业务状态       |

`management/` 和 `status/` 通过属性与插槽接收展示数据、通过事件通知操作，不直接请求业务 API 或使用业务 Store。业务状态文案与颜色映射保留在对应 feature。

业务模块可引用公共展示组件；公共展示组件不得反向引用业务模块或路由页面。`layout/` 是应用组合层，不供业务模块反向引用。禁止为了复用某个业务组件而把整个业务状态移入公共目录。

公共组件样式与组件就近维护，统一消费 `styles/tokens.css` 的令牌。页面负责位置与布局，组件负责自身外观与交互状态。
